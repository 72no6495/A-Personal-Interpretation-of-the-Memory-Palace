# A Personal Interpretation of the Memory Palace

記憶の宮殿の独自解釈 — 真っ白な部屋に、描いて、貼って、置いて、覚えておくための 3D メモアプリです。
ブラウザだけで動き（ビルド不要）、PC とスマホ（縦持ち・横持ち）の両方に対応しています。

## 起動方法

ES モジュールを使うため、ローカルの Web サーバー経由で開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます（three.js は `js/lib` に同梱）。

### GitHub Pages で公開する

リポジトリの **Settings → Pages → Build and deployment → Source** を **Deploy from a branch**（`main` / `/ (root)`）にすると、`main` に push するたびに自動で公開されます。

公開先：`https://<ユーザー名>.github.io/A-Personal-Interpretation-of-the-Memory-Palace/`

※ 保存データはブラウザごと・公開URLごとに保存されます。別の端末へ移すときはドアからバックアップを作成してください。

## 遊び方

- **タイトル画面**：新しい宮殿を作る／宮殿を読み込む／設定
- 新しい宮殿は壁・床・天井すべて真っ白な部屋。背後に白いドアがあります。
- **ドア**をクリック（タップ）すると、バックアップファイル（`.mpalace`）の作成や退出ができます。
  退出後も「宮殿を読み込む → バックアップファイルから読み込む」で戻ってこられます。
- 宮殿は端末内（IndexedDB）に自動保存されます（約1分ごと＋退出時）。

### ツール

| ツール | 内容 |
| --- | --- |
| 手 | 家具・画像を選択、ドラッグで移動、回転・拡大縮小・色変更・複製・削除 |
| ペン | 全8色。形（フリー／直線／矢印／四角／円）、太さ、濃さ、手ぶれ補正 |
| 消しゴム | 太さを変えて消す |
| 文字 | クリックした場所に文字を書く（ゴシック／明朝／手書き風）。「高画質」では小さい文字もくっきり表示され、手ツールで動かせる |
| 画像 | ファイルを読み込んで壁・床・家具に貼る。付箋（5色）も貼れる。上からペンで描ける |
| 家具 | 床・壁・天井・小物の4分類、計50種以上。テーブルや額縁などは描けて写真を飾れる。椅子・ソファ・ベッドの上や棚にも小物を置ける |

### 開閉・明かり・撮影

- タンス・キャビネット・クローゼット・吊り戸棚・デスク・ナイトテーブル・収納ボックス・小箱・ノートは、手ツールで扉・引き出し・ふたをクリック（タップ）すると開閉でき、中に小物を入れられます
- ランプやキャンドルはクリック（タップ）で点灯・消灯
- カレンダーは手ツールで選ぶと月を切り替えられます
- 撮影モード（カメラのボタン／`P`）：写真と動画（`V` で切り替え）
  - カメラ（`C` で切り替え）：通常／定点／手ブレ（強さを調整）／シアター（部屋の全体や家具・小物・壁の絵へ自動でカットが切り替わり、ゆっくり動く）
  - フィルター・縦横比（画面・16:9・シネマ・4:3・1:1・3:4・9:16）・グリッド・ビネット・フィルム粒子・ズーム
  - 動画は WebM で保存（720p／1080p、30／60fps、音も録る）。WebM で録画できないブラウザ（iPhone の Safari など）では MP4 になります
  - プレイヤーの姿は映りません。写真は端末に保存したり、そのまま宮殿に貼ったりできます

### 音

- 環境音：不規則な間隔で、低音・重低音・風の音が聞こえます。木の家具・時計・点いているライトがあると、その家具の位置からきしむ音・時計の音・電球の音も鳴ります（設定でオン／オフ・音量）
- グラモフォン（家具 → 小物）：手ツールでクリック（タップ）すると再生・停止。選ぶと「アンビエント／スロージャズ／スウィング／サイケテクノ」を切り替えられます。音はグラモフォンの位置から聞こえ、離れると小さくなります
- 音楽はその場で合成しているので、毎回少しずつ違う演奏になります（音声ファイルは使っていません）

### VR（Meta Quest 3 など）

WebXR に対応したヘッドセットのブラウザ（Meta Quest Browser など）で公開URLを開くと、画面右側に VR のボタンが出ます（メニューの「VR で入る」からも入れます）。

| 操作 | 内容 |
| --- | --- |
| 左スティック | 移動 |
| 右スティック | 30° ずつ向きを変える |
| トリガー（ハンドトラッキングではつまむ） | ツールを使う・メニューのボタンを押す |
| 右 A | 家具の回転 |
| 右 B | メニュー板を目の前に呼ぶ |
| 左 X / 左 Y | 元に戻す / やり直す |

- 左手のメニュー板から、手・ペン・消しゴム・家具を選び、色・太さ・家具の種類を変えられます
- 扉・引き出し・明かりはトリガーで開閉・点灯、ドアを選ぶと「保存して VR を終了」「ドアから出る」を選べます
- 文字・画像・撮影・バックアップは VR を終えてから使えます

### PC の操作

- `WASD` 移動 / マウス 視点 / クリック ツールを使う
- `Q` `E` ツール切替、`1`〜`6` ツール選択
- `F` 照準モード ⇄ カーソルモード（カーソルモードは文字を書くのに便利、右ドラッグで視点）
- `G` 見ている面の正面を向く、`Z` ズーム、`C` 色、ホイール・`[` `]` 太さ／大きさ
- `Shift`+ドラッグ 直線、`R` 回転、`T` 家具の色、`Delete` 削除、`Ctrl+D` 複製
- `Ctrl+Z` / `Ctrl+Y` 元に戻す／やり直す、`Ctrl+S` 保存、`H` 操作説明、`Esc` メニュー

### スマホの操作

- 画面左側をタッチ → その場所にスティックが出て移動
- 画面右側をスワイプ → 視点
- タップ → ツールを使う
- ペン・消しゴムでは「描画モード」になり、1本指で描く／2本指で視点。右側のボタンで移動モードに戻せます
- 設定の「移動スティック」を「固定」にすると、左下に常に薄く表示されるスティックで移動できます

### 全画面表示

タイトル画面右上・ゲーム中の右側のボタン・メニュー・設定から切り替えられます。
iPhone の Safari は全画面表示に対応していないため、共有メニューの「ホーム画面に追加」から開くと全画面で使えます。

## 構成

```
index.html
css/style.css
js/main.js        アプリ本体（画面遷移・保存・ドア）
js/world.js       部屋・ドア・家具・画像の管理と保存形式
js/surface.js     描ける面（キャンバステクスチャ）
js/furniture.js   家具カタログとモデル
js/tools.js       各ツール
js/input.js       PC／スマホの入力
js/ui.js          HUD・パネル・モーダル・設定
js/player.js      一人称カメラと当たり判定
js/audio.js       静かな効果音（WebAudio で合成）
js/storage.js     IndexedDB とバックアップファイル
js/lib/           three.js r170（MIT）
```
