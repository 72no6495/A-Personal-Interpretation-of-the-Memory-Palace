# A Personal Interpretation of the Memory Palace

記憶の宮殿の独自解釈 — 真っ白な部屋に、描いて、貼って、置いて、覚えておくための 3D メモアプリです。
ブラウザだけで動き（ビルド不要）、PC とスマホ（縦持ち・横持ち）の両方に対応しています。

## 起動方法

ES モジュールを使うため、ローカルの Web サーバー経由で開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます（three.js は `js/lib` に同梱）。

### GitHub Pages で公開する

リポジトリの **Settings → Pages → Build and deployment → Source** を **Deploy from a branch**（`main` / `/ (root)`）にすると、`main` に push するたびに自動で公開されます。

公開先：`https://<ユーザー名>.github.io/A-Personal-Interpretation-of-the-Memory-Palace/`

※ 保存データはブラウザごと・公開URLごとに保存されます。別の端末へ移すときはドアからバックアップを作成してください。

## 遊び方

- **タイトル画面**：新しい宮殿を作る／宮殿を読み込む／設定
- 新しい宮殿は壁・床・天井すべて真っ白な部屋。背後に白いドアがあります。
- **ドア**をクリック（タップ）すると、バックアップファイル（`.mpalace`）の作成や退出ができます。
  退出後も「宮殿を読み込む → バックアップファイルから読み込む」で戻ってこられます。
- 宮殿は端末内（IndexedDB）に自動保存されます（約1分ごと＋退出時）。

### ツール

| ツール | 内容 |
| --- | --- |
| 手 | 家具・画像を選択、ドラッグで移動、回転・拡大縮小・色変更・複製・削除 |
| ペン | 全8色。形（フリー／直線／矢印／四角／円）、太さ、濃さ、手ぶれ補正 |
| 消しゴム | 太さを変えて消す |
| 文字 | クリックした場所に文字を書く（ゴシック／明朝／手書き風） |
| 画像 | ファイルを読み込んで壁・床・家具に貼る。上からペンで描ける |
| 家具 | 床・壁・天井・小物の4分類、計40種。テーブルや額縁などは描けて、写真を飾れて、小物を置ける |

### PC の操作

- `WASD` 移動 / マウス 視点 / クリック ツールを使う
- `Q` `E` ツール切替、`1`〜`6` ツール選択
- `F` 照準モード ⇄ カーソルモード（カーソルモードは文字を書くのに便利、右ドラッグで視点）
- `G` 見ている面の正面を向く、`Z` ズーム、`C` 色、ホイール・`[` `]` 太さ／大きさ
- `Shift`+ドラッグ 直線、`R` 回転、`T` 家具の色、`Delete` 削除、`Ctrl+D` 複製
- `Ctrl+Z` / `Ctrl+Y` 元に戻す／やり直す、`Ctrl+S` 保存、`H` 操作説明、`Esc` メニュー

### スマホの操作

- 画面左側をタッチ → その場所にスティックが出て移動
- 画面右側をスワイプ → 視点
- タップ → ツールを使う
- ペン・消しゴムでは「描画モード」になり、1本指で描く／2本指で視点。右側のボタンで移動モードに戻せます

```
css/style.css

js/world.js       部屋・ドア・家具・画像の管理と保存形式
js/surface.js     描ける面（キャンバステクスチャ）
js/furniture.js   家具カタログとモデル
js/tools.js       各ツール
js/input.js       PC／スマホの入力
js/ui.js          HUD・パネル・モーダル・設定
js/player.js      一人称カメラと当たり判定
js/audio.js       静かな効果音（WebAudio で合成）
js/storage.js     IndexedDB とバックアップファイル
js/lib/           three.js r170（MIT）
```
